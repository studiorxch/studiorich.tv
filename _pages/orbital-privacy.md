# Orbital Privacy Policy

**Last Updated:** June 2026

Orbital is a browser extension developed by StudioRich.

## Data Collection

Orbital does not collect, store, transmit, sell, or share personal information.

Orbital does not collect:

- Names

- Email addresses

- Passwords

- Payment information

- Browsing history

- Website content

- Personal communications

- Location information

## Local Storage

Orbital stores user preferences locally using Chrome Extension Storage.

These preferences may include:

- Orbital enabled/disabled state

- Scroll settings

- Dock position

- User interface preferences

This information remains on the user's device and is never transmitted to StudioRich or third parties.

## Third-Party Services

Orbital does not transmit data to external servers.

Orbital does not use analytics, advertising networks, tracking pixels, user profiling services, or advertising identifiers.

## Changes

This policy may be updated as Orbital evolves. Any updates will be reflected on this page.
